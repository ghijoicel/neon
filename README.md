# Neon Siege — CinemaX Action
Shooter arena top-down: tembakan otomatis ke musuh terdekat, kamu fokus menghindar. Tiga jenis musuh (pengejar, tank, penembak),
gelombang makin sulit, combo hingga ×5, pickup ❤️ dan ⚡ (tembak ganda cepat), serta dash kebal sesaat.

**Android:** geser jari di layar = gerak (joystick melayang) · tombol ⚡ = dash · ⛶ layar penuh (otomatis mengunci landscape bila didukung)
· layar tidak mati saat bermain (Wake Lock) · getar saat terkena · jeda otomatis saat aplikasi ditinggalkan.
Untuk tampilan tanpa bilah browser: Chrome ⋮ → "Tambahkan ke layar utama". **Desktop:** WASD/panah, Spasi = dash, P jeda, F layar penuh, M suara.

Buka via hosting statis (lihat panduan GitHub Pages), bukan dari file manager HP. iPhone Safari tidak mendukung Fullscreen API.
Keamanan: CSP ketat, tanpa innerHTML/eval/jaringan; rekor di localStorage (bukan anti-curang). Uji: `node tests/test.js`.
